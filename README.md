# وصل | Wasl

تطبيق دردشة كامل يعمل داخل المتصفح — بواجهة عربية وإنجليزية (RTL/LTR)، بدون خادم وبدون إنترنت.
A complete, working chat application that runs in your browser — Arabic + English UI (RTL/LTR), no server, no internet required.

> **🌐 جرّبها الآن:** **https://hdm8097-sketch.github.io/wasl/** — المستودع: **https://github.com/hdm8097-sketch/wasl**
>
> النموذج التجريبي (demo) للحساب: **demo / wasl1234** — أو اضغط «الدخول كضيف» لإنشاء حساب فوري.

## التشغيل | Running

**الطريقة الأولى (موصى بها) — خادم محلي:**

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\Sa E1\Documents\wasl\server.ps1"
```

ثم افتح: **http://localhost:8873/**

**الطريقة الثانية:** افتح `index.html` مباشرة في المتصفح (نظام ملفات `file://` — بعض المتصفحات تقيّد التخزين المحلي عليه، لذا الخادم المحلي أفضل).

**النشر على GitHub Pages:** المستودع مُفعَّل عليه Pages من فرع `main` — كل دفع إلى `main` يعيد نشر الموقع تلقائياً:

```powershell
git add -A; git commit -m "update"; git push
```

لا توجد خطوة بناء (build) — لا Node.js ولا npm ولا حزم خارجية. كل الملفات كلاسيكية (classic scripts).

## المميزات | Features

**المحادثات**
- رسائل نصية، ردود، تعديل، حذف، إعادة توجيه، تثبيت، نسخ، حفظ، ترجمة، تدمير ذاتي (-self-destruct)
- تفاعلات (تفاعلات emoji على الرسائل)، ردود سريعة، مؤشر كتابة، حالة «يكتب…»
- بحث داخل المحادثة مع ترقيم النتائج والتنقل بينها (`Ctrl+Shift+F`)
- محادثات خاصة، مجموعات، قنوات، وبوتات ذكية ترد بالعربية والإنجليزية (حسابات + رياضيات + كلمات مفتاحية)
- تصويتات (polls) ومهام (tasks) تفاعلية داخل الشات
- ملصقات (stickers) وإيموجي، إرفاق ملفات وصور ورسائل صوتية

**الواجهة**
- عربي/إنجليزي مع زر تبديل واتجاه تلقائي (`Alt+G`)
- 4 ثيمات + ألوان تمييز (accents) متعددة + خلفيات محادثة (wallpapers) + أحجام خط
- قائمة أوامر سريعة (Command Palette) بـ `Ctrl+K`
- مجلدات محادثات، مقص (Archive)، كتم، بحث في القائمة الجانبية
- قصص (Stories) مع مؤشر تقدم، رد على القصة كرسالة، وتفاعلات
- درج (Drawer) للمعلومات: وسائط، ملفات، روابط، صوت + بحث وكتم وعرض الملف الشخصي
- مكالمات صوتية وفيديو (واجهة محاكاة — انظر «الحدود» أدناه)
- لوحة رمز PIN لقفل التطبيق + تغيير/إلغاء كلمة المرور
- اختصارات لوحة مفاتيح كاملة (انظر الجدول أدناه)

**البيانات**
- كل شيء محفوظ محلياً في `localStorage` — لا يغادر جهازك
- نسخ احتياطي: تصدير/استيراد ملف JSON (الاستيراد يعيد تحميل التطبيق ويستعيد كل شيء)
- مزامنة فورية بين تبويبات المتصفح عبر `BroadcastChannel` + أحداث `storage`
- مساحة عمل منفصلة لكل حساب (`state.workspaces[userId]`)

## الخصوصية والبيانات | Privacy & data

- **لا خادم، لا إنترنت، لا تتبّع.** التطبيق لا يرسل أي طلب شبكة.
- مفاتيح التخزين: `wasl.db.v1` (البيانات)، `wasl.media.v1` (الوسائط)، `wasl.session` (الجلسة)، `wasl.lang`، `wasl.theme`.
- كلمات المرور تُخزَّن مجزّأة بـ SHA-256 مع ملح (salt)، ولا تُحفظ كنص صريح.
- **حد الملفات:** الملفات الأكبر من **900KB** لا تُحفظ بالكامل في `localStorage` — تُحفظ بياناتها الوصفية فقط مع تنبيه، لتفادي امتلاء المساحة.
- إن تعذّر قراءة قاعدة البيانات (تلف/نسخة غير متوافقة) يُؤخذ نسخة احتياطية منها في `wasl.db.v1.bak` قبل إعادة الإنشاء، فلا تُفقد البيانات بصمت.
- «مسح كل البيانات» من الإعدادات يحذف القاعدة والوسائط ويُعيد تحميل الصفحة.

### حدود يجب ذكرها | Known limitations

1. **المكالمات واجهة محاكاة فقط** — لا يوجد WebRTC ولا اتصال شبكي حقيقي، لعدم وجود خادم إشارة (signaling server). الصورة/الصوت داخل شاشة المكالمة مُحاكاة.
2. الرسائل تُخزَّن **مفكّكة (plaintext)** محلياً؛ «الدردشة السرية» ميزة واجهة وليست تشفيراً حقيقياً طرف-لطرف. لا تستخدم التطبيق لبيانات حساسة فعلياً.
3. مزامنة «الأجهزة» بين تبويبات المتصفح فقط (نفس المتصفح ونفس المنشأ origin) — لا مزامنة عبر أجهزة مختلفة.
4. التطبيق تجريبي/تعليمي، غير جاهز للاستخدام الإنتاجي.

## إمكانية الوصول | Accessibility

- نتائج Lighthouse: **Accessibility 100 · Best Practices 100 · SEO 100**
- كل زر أيقونة له `aria-label` مُولَّد تلقائياً ويتبع اللغة الحالية (`autoLabel`)
- تباين نصوص ≥ 4.5:1 في كل الثيمات، ألوان تمييز محسوبة وقت التشغيل (`--accent-solid`)
- دعم لوحة المفاتيح بالكامل: `Esc` يغلق أعلى طبقة مفتوحة، تنقّل بالأسهم في قوائم الأوامر
- تخطيط عناوين منطقي (h1 → h2 → h3)، مجموعات `role="group"` بدل `tablist` غير الصحيح
- مساحة نقر ≥ 24×24 بكسل لجميع عناصر التحكم

## البنية | Structure

```
wasl/
├── index.html          الهيكل وكل المعرفات (+ SVG sprite للأيقونات)
├── server.ps1          خادم محلي بسيط (PowerShell) على المنفذ 8873
├── assets/
│   ├── css/app.css     نظام التصميم، الثيمات، RTL، الوسائط استعلامية
│   └── js/
│       ├── i18n.js     الترجمة (ar/en) + تبديل الاتجاه
│       ├── store.js    الحالة، البذور (seed)، الحفظ، المزامنة، النسخ الاحتياطي
│       ├── ui.js       عناصر مشتركة: مودالات، تنبيهات، حوار، أصوات، ثيم/لون
│       ├── auth.js     حسابات محلية، SHA-256، قفل PIN
│       ├── bot.js      منطق الردّ التلقائي للبوتات
│       ├── chat.js     المحادثة: الرسائل، القوائم السياقية، البحث، الإرفاق
│       └── app.js      التشغيل، القائمة الجانبية، الإعدادات، القصص، المكالمات
└── README.md
```

**ترتيب التحميل:** `i18n → store → ui → auth → bot → chat → app` (يعتمد كل ملف على ما قبله عبر `window.*`).
